# Function Pointers

This directory contains projects and exercises about function pointers in C.

## Description

The goal of this project is to learn how function pointers work in C, how to declare and use them, and how to pass functions as arguments to other functions.

## Learning Objectives

•⁠  ⁠Understand what function pointers are
•⁠  ⁠Declare function pointers
•⁠  ⁠Use function pointers
•⁠  ⁠Pass functions as parameters
•⁠  ⁠Understand what a function pointer stores
•⁠  ⁠Work with callback functions

## Files

•⁠  ⁠⁠ 0-print_name.c ⁠ - Prints a name using a function passed as a parameter.
•⁠  ⁠⁠ function_pointers.h ⁠ - Header file containing function prototypes.
