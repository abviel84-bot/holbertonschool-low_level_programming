# Singly Linked Lists

This directory contains projects and exercises about singly linked lists in C.

## Learning Objectives

•⁠  ⁠Understand when and why to use linked lists
•⁠  ⁠Understand how singly linked lists work
•⁠  ⁠Learn how to build and use linked lists
•⁠  ⁠Learn how to traverse a linked list

## Files

•⁠  ⁠⁠ 0-print_list.c ⁠ - Prints all the elements of a ⁠ list_t ⁠ list.
•⁠  ⁠⁠ lists.h ⁠ - Header file containing the structure and function prototypes.
