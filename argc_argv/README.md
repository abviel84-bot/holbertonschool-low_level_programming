# argc_argv

This directory contains exercises about command-line arguments in C.

## Description

In this project, I will learn how to use ⁠ argc ⁠ and ⁠ argv ⁠ to work with arguments passed to a program from the command line.

## Learning Objectives

•⁠  ⁠Understand what ⁠ argc ⁠ and ⁠ argv ⁠ are
•⁠  ⁠Use command-line arguments in C
•⁠  ⁠Understand how arguments are passed to a program
•⁠  ⁠Use ⁠ argv[0] ⁠ to access the program name

## Files

•⁠  ⁠⁠ 0-whatsmyname.c ⁠ - Prints the name of the program.

## Compilation

Files are compiled using:

gcc -Wall -Werror -Wextra -pedantic -std=gnu89
